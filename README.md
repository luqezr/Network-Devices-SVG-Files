# Network Devices SVG Files / Vendor Network Device Icons (SVG)

A collection of network device icons converted from publicly available vendor Visio stencils (Cisco, Palo Alto Networks / Panorama, and others) into clean SVG format.

These icons are intended for use in modern diagramming tools that support SVG, such as:

- [draw.io / diagrams.net](https://app.diagrams.net/)
- Lucidchart
- yEd
- Excalidraw
- Microsoft Visio (via import)
- Any other tool that accepts SVG

## Why this repository exists

Many vendors provide excellent Visio stencils, but they are locked into the proprietary Visio format. Converting them to SVG makes them usable across a much wider range of tools while preserving the original visual design as closely as possible.

## Usage

1. Clone or download the repository.
2. Import the desired `.svg` files into your diagramming tool.
3. In draw.io: **File → Import from → Device** (or just drag & drop the SVG).
